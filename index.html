🛡️ قاعدة الأمان
⚠️ استخدم Nmap وWireshark فقط على جهازك أو معمل عندك تصريح واضح بفحصه. لا تفحص أجهزة أشخاص آخرين أو مواقع الإنترنت للتجربة.
1️⃣ أولًا: اعرف IP المعمل
افتح Command Prompt
اضغط Windows واكتب cmd ثم افتحه.
اكتب:
ipconfig
ابحث عن IPv4 Address، مثل:
IPv4 Address . . . : 192.168.1.20
مهم: العنوان عندك قد يكون مختلفًا. استخدم عنوان جهاز المعمل الذي حدده المدرس.
2️⃣ ثانيًا: اعمل فحص Nmap
افتح Command Prompt واستخدم Nmap المثبت عندك.
اكتب:
nmap -sV LAB-IP
استبدل LAB-IP بعنوان هدف المعمل المصرّح به.
شكل النتيجة قد يكون مثل:
PORT STATE SERVICE
22/tcp open ssh
80/tcp open http
443/tcp open https
🔍 اقرأ النتيجة في 4 أسئلة
الخانةمعناها ببساطة
PORTرقم الباب
STATEالباب مفتوح أم لا؟
SERVICEالخدمة الموجودة
tcp / udpبروتوكول النقل

3️⃣ ثالثًا: شوف حركة الشبكة بـ Wireshark
افتح Wireshark واختار واجهة الشبكة المستخدمة في المعمل: Wi‑Fi أو Ethernet.
Start لبدء Capture.
نفّذ النشاط الذي حدده المدرس داخل المعمل فقط.
Stop لإيقاف الالتقاط.
جرّب الفلتر:
tcp.port == 80
لو لم يظهر شيء، فهذا طبيعي إذا لم يوجد Traffic على هذا المنفذ.
اختار Packet وابحث عن Source وDestination وProtocol.
